## Контекст (установлено исследованием)

Проект ducalis-tg сейчас на **tg v2** (`VersionTg=v2.3.95`, `go install .../tg/v2/cmd/tg`, `go 1.24`, v2-синтаксис `tg transport --services`). Цель — **tg v3 + плагины tgp-go (astg+server) + встроенные `tg skills install`**, используя как референс проверенный `test-todo2` из репо microcode (там v3 работает end-to-end).

**Scope (по вашему выбору):** только microcode-инфраструктура под v3 + PRD + удаление старого v2-транспорта. Сами `go.mod`/`Makefile`/контракты/regenerцию оставляем loki — это кодогенерируемый код, его нельзя писать руками.

## Ключевая находка аудита (влияет на удаление)

В `internal/transport/` **перемешаны** сгенерированные и hand-written файлы:
- **СГЕНЕРИРОВАНО (удаляем, 46 файлов, top-level):** все `*service-*.go` (32) + `context.go`, `errors.go`, `fiber.go`, `header.go`, `http.go`, `jsonrpc.go`, `metrics.go`, `options.go`, `server.go`, `version.go` (14). Все несут маркер `// GENERATED BY 'T'ransport 'G'enerator. DO NOT EDIT.`
- **HAND-WRITTEN (ОСТАВЛЯЕМ):** `internal/transport/tracer/` (4 файла), `internal/transport/context/context.go` (1), `internal/transport/viewer/` (6) — реальный OTel/Viewer код без маркера.
- **pkg/client/ — ВСЁ hand-written, ОСТАВЛЯЕМ:** `go/jsonrpc/` (11), `go/cb/` (8), `go/hasher/` (5), `ts/jsonrpc-client.js` (1).
- `tools.go` отсутствует.
